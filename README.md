# Photonic

A keyboard-first photo culling app for macOS. Point it at a folder of photos (subfolders included; to review one subfolder on its own, open it as its own library) and go through them one at a time: **↑ Like** ⸜(｡˃ ᵕ ˂ )⸝♡, **↓ Meh** ¯\\_(ツ)_/¯, **←/→** to move. Decisions are stored in a local SQLite database. **Photos are never moved, changed or deleted.**

See [PLAN.md](PLAN.md) for the full design and milestone notes.

## Using it

| Key | Action |
|---|---|
| `↑` / `↓` | Like / Meh (the default playlist keys), then jump to the next unreviewed photo |
| your keys | Put the photo in the playlist you gave that key (Playlists → Manage Playlists…) |
| `←` / `→` | Previous / next photo |
| `U` | Clear the mark |
| `⌘Z` | Undo (including a whole "hide duplicates" batch) |
| `1` `2` | All / Unreviewed (`3` = Duplicates); playlists are in the Playlists dropdown |
| `S` / `R` | Order: filename → date → random / reshuffle |
| `Space` | Zoom to 100% (drag to pan) |
| `C` / `O` | Copy the full path / show in Finder |
| `F` | Put a whole folder in a playlist |
| `H` | Hide toolbars |
| `?` | All shortcuts |

**Export** a playlist (e.g. your Likes, for prints) from Playlists → Manage Playlists…: it copies the photos into one folder, keeping their names or renaming them `001.jpg`… or `20190704_153012.jpg`. The originals stay where they are.

The **View** menu has the theme (4 palettes), light/dark, animations, and the **Duplicate Detection** toggle.

## Development

```sh
npm install          # also rebuilds native modules for Electron
npm run dev          # app with hot reload (data: ~/Library/Application Support/Photonic-dev)
npm test             # unit tests (Vitest)
npm run test:e2e     # builds, then drives the real app with Playwright
npm run typecheck
npm run format
```

## Building the app

```sh
npm run dist                 # → dist/Photonic-<version>-arm64.dmg and dist/mac-arm64/Photonic.app
npm run test:e2e:packaged    # runs the e2e suite against the packaged app
```

The build is ad-hoc signed, which is enough to run it on your own Mac. The first time, you may need to right-click → Open (it isn't notarized). Data lives in `~/Library/Application Support/Photonic/` (`photonic.db`, plus daily backups in `backups/`).

The app icon is generated by `npm run icon` (pixel art in `scripts/make-icon.mjs`).
